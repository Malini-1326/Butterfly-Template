# Butterfly - Website

A modern website template built using HTML, CSS, and AOS (Animate On Scroll) animations.

## 🛠️ Technologies Used

- HTML5
- CSS3
- AOS (Animate On Scroll)

## ✨ Features

- Clean and modern website design
- Smooth scroll animations using AOS
- Attractive visual sections
- Custom CSS styling
- Image-based content sections
- Simple and organized structure

## 📁 Project Structure

```text
Butterfly-Template/
│
├── css/
│   ├── aos.css
│   └── style.css
│
├── images/
│
├── dist/
│
└── index.html
```
## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Malini-1326/Butterfly-Template.git
cd Butterfly-Template
```

### 2. Open the Website

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code.
